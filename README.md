# Nonstop Fantasy Leagues

Nonstop is a turn-based Fantasy Football Simulator (FFS) built around simulated National Football League (NFL) seasons.

The project aims to develop a functional, extensible simulator using established software engineering principles and AI-assisted development.

## Features

The planned capabilities include:

- Simulation of individual NFL games.
- Simulation of complete NFL seasons.
- Fantasy league creation and management.
- Fantasy drafting, roster management, and scoring.
- Persistent simulation data with save and resume functionality.
- User interface for interacting with the simulator.

## Architecture

Nonstop is designed around three main components:

- **Simulation Engine:** Executes football games independently of the user interface.
- **Data Storage:** Manages simulation data, results, and state.
- **User Interface:** Provides interaction with and visualization of the simulator.

## Development Approach

Nonstop is developed incrementally using AI coding agents and specialized domain experts.

The project emphasizes modular architecture, domain modeling, automated testing, and software quality.

## Project Status

Early development. Requirements and architecture are being defined.
